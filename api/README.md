# FastAPI Application (`api/`)

FastAPI backend service providing REST API endpoints for user profiles, matches, reports, media metadata, payments, referrals, analytics, and admin controls.

## Endpoint Structure (Planned)
- `GET /api/v1/health`
- `GET /api/v1/profiles`
- `POST /api/v1/matches`
- `POST /api/v1/reports`
- `POST /api/v1/media`
- `POST /api/v1/payments`
- `POST /api/v1/referrals`
- `GET /api/v1/admin`
- `GET /api/v1/statistics`
