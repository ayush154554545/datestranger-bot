# DateWithStranger — Service Setup & Authentication Guide (Phase 0)

This guide provides step-by-step instructions for acquiring, configuring, and localizing credentials for all external services required by **DateWithStranger**.

---

## 1. TELEGRAM BOT API
────────────

1. **Create account**: Register/Log in to Telegram on desktop or mobile.
2. **Create project**: Start a chat with `@BotFather` on Telegram.
3. **Select required region**: N/A (Global Telegram Infrastructure).
4. **Configure required settings**:
   * Send `/newbot`.
   * Provide Bot Name: `DateWithStranger`.
   * Provide Bot Username: ending in `bot` (e.g. `DateWithStrangerBot` or `testdate27_bot`).
   * Disable groups if not needed: `/setjoingroups` → `Disable`.
   * Enable privacy mode: `/setprivacy` → `Enable`.
5. **Create credentials**: Copy the HTTP API token generated by `@BotFather`. Also fetch your own Telegram user ID by messaging `@userinfobot`.
6. **Store credentials locally**: Save securely in local credential manager.
7. **Add to `.env`**:
   ```env
   BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ADMIN_ID=8835644904
   ```
8. **Run verification**:
   ```bash
   python scripts/check-connectivity.py --service telegram
   ```

## 2. SUPABASE POSTGRESQL
────────────

1. **Create account**: Register at [supabase.com](https://supabase.com).
2. **Create project**: Click "New Project" in your Supabase organization.
3. **Select required region**: Choose region closest to your target userbase (e.g., `AWS ap-south-1 (Mumbai)` or `AWS us-east-1 (N. Virginia)`).
4. **Configure required settings**:
   * Set a strong Database Password.
   * Enable Row Level Security (RLS) policies.
5. **Create credentials**:
   * Go to Project Settings → API.
   * Copy `Project URL`.
   * Copy `anon` key.
   * Copy `service_role` key.
   * Go to Project Settings → Database → Connection string → URI (`postgresql://postgres:[password]@db.[ref].supabase.co:5432/postgres`).
6. **Store credentials locally**: Save securely.
7. **Add to `.env`**:
   ```env
   SUPABASE_URL=https://<project-ref>.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=<service-role-jwt>
   SUPABASE_ANON_KEY=<anon-jwt>
   SUPABASE_DB_URL=postgresql://postgres:<password>@db.<project-ref>.supabase.co:5432/postgres
   ```
8. **Run verification**:
   ```bash
   python scripts/check-connectivity.py --service supabase
   ```

## 3. REDIS (UPSTASH / REDIS CLOUD / LOCAL DOCKER)
────────────

1. **Create account**: Register at [upstash.com](https://upstash.com) or [redis.io](https://redis.io), OR use local Docker.
2. **Create project**: Create a new Redis database instance.
3. **Select required region**: Same region as Supabase server.
4. **Configure required settings**: Enable TLS, eviction policy `volatile-lru` or `noeviction` for queues.
5. **Create credentials**: Copy host, port, password, or unified connection string `rediss://...`.
6. **Store credentials locally**: Save securely.
7. **Add to `.env`**:
   ```env
   REDIS_HOST=localhost
   REDIS_PORT=6379
   REDIS_PASSWORD=
   REDIS_URL=redis://localhost:6379/0
   ```
8. **Run verification**:
   ```bash
   python scripts/check-connectivity.py --service redis
   ```

## 4. CLOUDFLARE R2 OBJECT STORAGE
────────────

1. **Create account**: Register at [cloudflare.com](https://dash.cloudflare.com).
2. **Create project**: Navigate to R2 Object Storage → Create Bucket (`datestranger-media`).
3. **Select required region**: Automatic / Location Hint.
4. **Configure required settings**: Set CORS headers for web access if needed. Keep bucket private.
5. **Create credentials**:
   * Go to R2 → Manage R2 API Tokens.
   * Click "Create API Token".
   * Select permissions: `Edit` (Read & Write).
   * Copy `Account ID`, `Access Key ID`, and `Secret Access Key`.
6. **Store credentials locally**: Save securely.
7. **Add to `.env`**:
   ```env
   CLOUDFLARE_ACCOUNT_ID=<account-id>
   R2_ACCESS_KEY_ID=<access-key-id>
   R2_SECRET_ACCESS_KEY=<secret-access-key>
   R2_BUCKET_NAME=datestranger-media
   ```
8. **Run verification**:
   ```bash
   python scripts/check-connectivity.py --service r2
   ```

## 5. DISCORD WEBHOOK LOGGING
────────────

1. **Create account**: Register on Discord.
2. **Create project**: Create a dedicated private Discord server for system administration.
3. **Select required region**: Default.
4. **Configure required settings**: Create text channels:
   * `#status`, `#alerts`, `#chat-logs`, `#media-logs`, `#voice-logs`
   * `#girl-users`, `#boy-users`, `#other-users`
   * `#girl-media`, `#boy-media`, `#other-media`
5. **Create credentials**: In each channel → Edit Channel → Integrations → Webhooks → Create Webhook → Copy Webhook URL.
6. **Store credentials locally**: Save in local credentials manager.
7. **Add to `.env`**: Assign respective URLs to `STATUS_WEBHOOK`, `ALERTS_WEBHOOK`, `CHAT_LOG_WEBHOOK`, etc.
8. **Run verification**:
   ```bash
   python scripts/check-connectivity.py --service discord
   ```
